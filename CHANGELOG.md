# Changelog

All notable changes to this project are documented in this file.

## [v1.0.0-flarum2] - 2026-09-26

### Added

- Initial Flarum 2 RTL asset compilation compatibility patch.
- Added compatibility improvements for `irmmr/flarum-ext-rtl`.
- Added RTL CSS sidecar asset generation support.
- Added safer LESS cache handling for concurrent asset compilation.

### Changed

- Updated LESS compiler behavior for Flarum 2 asset pipeline.
- Improved compatibility with Flarum 2 frontend asset publishing workflow.

### Fixed

- Missing RTL asset publishing during Flarum 2 asset compilation.
- LESS cache corruption issues during concurrent compilation.

### Documentation

- Added installation instructions.
- Added MIT License.
- Added project documentation for Flarum 2 compatibility.
